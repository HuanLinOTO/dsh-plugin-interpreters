## 改动

**Host**
- `src/config.ts`：schema 由裸 `schemastery` 改为 `@deepseek-ai/schemastery` 并给 `pythonPath`/`nodePath`/`timeoutMs` 加 `.volatile()`；新增 `InterpretersEntryConfig`（`Volatile<T>` 字段）。
- `src/settings.ts`：删除 `SettingsScope` import + `settings.register`；改为 `settings.configure({ auto: false }, ctx.fiber)`；`source()` 每次从 volatile 引用 `.get()`。
- `src/index.ts`：`apply(ctx, config: InterpretersEntryConfig)`；工具以 `registerTools(ctx, () => bridge.source())` 注册（执行时读实时配置）；删除 `bridge.onChange` 重注册块。
- `src/tools.ts`：`registerTools` 接受 `ResolvedConfig | (() => ResolvedConfig)`；description 用注册时快照，`execute` 用实时读值。
- `src/gateway.ts`：`SettingsProvider`（rc.1 不再导出）→ 本地 duck type `SettingsWriter`，并 `import type {} from '@deepseek-ai/dsh-settings'` 以拿到 `ctx.settings` 的类型合并。
- 裸 `schemastery`（最高 3.18.0，无 `.volatile()`）→ `@deepseek-ai/schemastery ^3.18.4`。

**Web Client**
- `src/client/index.ts`：`settings.plugin.item` → `plugins.row.config`，key `@huanlin/dsh-plugin-interpreters#interpreters`；`dsh.client.inject` 用 `dsh-client-ui-plugin-manager` 换掉 `dsh-client-ui-settings-plugins`。
- `src/client/InterpretersCard.tsx`：`IconChevronDownOutline14` → `IconChevronDownOutlineMedium`；props 增 `PropsRuntime<'plugins.row.config'>`；`view === 'summary'` 渲染 `t('intro')`。

**配置/打包**
- `package.json` peer/meta + `dsh.client.inject`；`tsconfig.json` paths（删 `ui-settings-plugins`，增 `ui-plugin-manager`）。
- `tests/gateway.spec.ts`：mock bridge 去掉 `onChange`，source 返回 `ResolvedConfig`。
- 重建 `lib/`（`tsc -p tsconfig.build.*` + `scripts/build-client.mjs` + `tsc -p tsconfig.*`）。

## pending / 残余风险

- **工具 description 的实时刷新（pending review）**：rc.2 行为是"设置提交即 dispose+重注册工具，模型立即可见新路径"。rc.1 的 live-config 机制本应提供实例内 `loader/volatile-update` 事件，但在已发布的 rc.1 cohort 中**不存在**：`@deepseek-ai/cordis-plugin-loader@1.0.5` 的 `Events` 只有 `loader/config-update|entry-init|partial-dispose|patch-context`，`@deepseek-ai/cordis@4.0.4` 亦无该事件（已在 registry 包内全文检索确认）。因此本迁移保留"执行时读实时配置"（`run_python`/`run_node` 的实际解释器路径实时生效），但**模型可见的 description 文案只在挂载时生成**。待上游提供 volatile 更新事件后可补回重注册。
- **本地 dsh checkout 版本**：`D:/Projects/deepseek-harness/dsh` 停在 `0.1.5-rc.2+139`，不含 `ui-plugin-manager`，仓内 `tsconfig.json` 的绝对 paths 目前无法解析 rc.1 专有类型；本次校验用临时 `tsconfig.rc1.json` / `tsconfig.build.rc1.json`（paths 指向 registry 0.1.7-rc.1）完成，校验后已删除。checkout 更新到 rc.1 后仓内 `pnpm typecheck` 即可通过。
